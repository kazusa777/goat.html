常用 Windows 批次檔 (.bat) 腳本介紹

1. 快速開啟「網路連線」設定

功能說明：直接呼叫 Windows 控制台的網路介面卡設定視窗（ncpa.cpl），不用再層層點選控制台，執行完自動關閉視窗。

@echo off
start ncpa.cpl
exit

2. 快速開啟「電源選項」設定

功能說明：直接開啟系統的電源管理設定（powercfg.cpl），方便快速切換效能模式或調整休眠設定。

@echo off
start control powercfg.cpl
exit

3. 批次壓縮資料夾（含排除功能）

功能說明：將當前目錄下的所有子資料夾，透過 WinRAR 分別壓縮成獨立的 .zip 檔，並可設定跳過特定名稱的資料夾。執行完畢會暫停畫面供確認。

@echo off
chcp 65001 >nul
for /d %%i in (*) do (
    if /i not "%%i"=="要排除的資料夾名稱1" if /i not "%%i"=="要排除的資料夾名稱2" if /i not "%%i"=="要排除的資料夾名稱3" (
        "C:\Program Files\WinRAR\WinRAR.exe" a -afzip "%%i.zip" "%%i\"
    )
)
pause

4. GPU 加速批次檢查影片損壞

功能說明：掃描當前資料夾內的常見影片格式（mp4, mkv, avi, mov），利用 FFmpeg 搭配 NVIDIA CUDA 硬體加速解碼測試。若發現壞軌或編碼錯誤，會自動將錯誤訊息輸出至 error_log.txt。

@echo off
chcp 65001 >nul
echo 開始使用 GPU 檢查資料夾內的所有影片...
echo ========================================

for %%f in (*.mp4 *.mkv *.avi *.mov) do (
    echo 正在檢查: "%%f"
    ffmpeg -hwaccel cuda -v error -i "%%f" -f null - 2>> error_log.txt
)

echo ========================================
echo 檢查完畢！如果有發現壞軌或錯誤，會記錄在 error_log.txt 裡面。
pause

5. 一鍵啟動 Node.js 專案

功能說明：先將工作路徑切換到這個批次檔所在的資料夾（避免路徑錯誤），接著執行 npm start 啟動專案伺服器。

@echo off
cd /d "%~dp0"
npm start
pause

6. 一鍵啟動 Python 虛擬環境專案

功能說明：先將工作路徑切換到這個批次檔所在的資料夾（避免路徑錯誤），接著呼叫專案內建的 .venv 虛擬環境執行 main.py 主程式。

@echo off
cd /d "%~dp0"
.\.venv\Scripts\python.exe main.py
pause
