ERObook V4.0 · PROJECT WORKFLOW

專案完整流程圖

從 Electron 啟動與本機書架，到漫畫網站資料、下載佇列和本機匯出。每張圖聚焦一個主要流程，保留使用者可見的分支和資料去向。

01 啟動與入口 02 書架與閱讀 03 下載與匯出 資料保存位置
01

啟動與入口

開發時由 npm start 啟動；免安裝版由執行檔啟動。Electron 主程序準備本機設定與 preload IPC 橋接，再依書目索引和起始畫面設定進入功能頁。

02

書架與閱讀

既有索引可直接瀏覽；管理書架時選擇路徑和掃描深度，掃描成功後更新 SQLite。書籍可進入閱讀器，也能管理檔案或執行重複比對。

03

漫畫下載與匯出

下載器 Vue 畫面透過 preload IPC 呼叫 Electron 主程序中的後端。網站瀏覽、登入需求、任務佇列、暫存、匯出與回到本機書架如下。

DATA DESTINATIONS

三種資料，各自保存

LOCAL LIBRARY

書架設定與索引

開發時：專案根目錄的 LibraryData\setting\local\；打包後：執行檔旁的 LibraryData\setting\local\。
保存書架路徑、偏好、搜尋紀錄和 SQLite 書目索引；漫畫原檔仍在使用者選擇的位置。

DOWNLOADER DATA

下載器設定與日誌

位於程式旁的 data；包含下載器設定、API 網域記憶和日誌，與書架索引分開。

COMIC OUTPUT

漫畫與匯出檔

下載圖片、可選中繼資料、CBZ 和 PDF 放在輸出目錄的 漫畫\書名。要在書架閱讀，需把輸出目錄加入書架並重新掃描。

Scope: user-visible end-to-end flows based on the current source and README. IPC channel names, every setting field, parser branches, and image-processing internals are grouped into their parent steps.
