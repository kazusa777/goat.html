## 網頁操作

- 首頁會自動列出儲存庫裡的 HTML 網頁，也可以用搜尋框找頁面。
- 右上角「切換頁面」可以開啟其他網頁。
- 拖曳右上角的導覽按鈕可以移動整組按鈕；拖曳後會固定位置。也可以按圖釘固定或解除固定，切換頁面後位置會保留。
- 新增 HTML 並提交後，首頁會自動把它加入清單；GitHub Actions 會替新頁面加入共用導覽。
